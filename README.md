# FitTrack

Aplicativo acadêmico para organização de treinos de academia, desenvolvido com React Native, TypeScript e Expo.

## Funcionalidades

- Cadastro e login com armazenamento local.
- Criação, edição e exclusão de fichas de treino.
- Organização de exercícios, séries e repetições.
- Catálogo de exercícios com nomes em português.
- Acompanhamento do treino com cronômetro.
- Histórico de sessões concluídas.
- Resumo semanal de atividades.

## Tecnologias

- React Native
- TypeScript
- Expo
- React Navigation
- AsyncStorage
- Expo SecureStore

## Dados

As contas, os treinos e o histórico ficam salvos no aparelho. O catálogo de exercícios utiliza o Free Exercise DB, consultado pela API do GitHub.
